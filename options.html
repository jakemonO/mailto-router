Mailto Router

Email links open in the provider marked as default. Each provider is a URL template with {to} {cc} {bcc} {subject} {body} placeholders. Values are URL-encoded; use {raw:subject} etc. for unencoded, or {mailto} for the whole original link. Parameters left empty are dropped.

Try it

Click a real mailto link (tests the Firefox handler setting)

Make Firefox use it

Open Firefox Settings → General → Applications, search for mailto, and choose Use Mailto Router. If it isn't listed, click a mailto link once (the one above works) and pick Mailto Router in the dialog.
